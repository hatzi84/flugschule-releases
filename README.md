# FlugSchule – Installationsdateien

Installationsdateien der Flugschul-Software für Microsoft Flight Simulator 2024. Der Quellcode ist privat.

**Installation:** Im neuesten [Release](../../releases/latest) die Datei `FlugSchule.App-win-Setup.exe` herunterladen und starten. Danach kommen Updates über den Knopf „Update installieren“ in der App.

Für Live-Daten aus MSFS 2024 wird das MSFS-2024-SDK benötigt (im Sim: Entwicklermodus → „Help“ → „SDK Installer“). Die SimConnect-Dateien werden nicht mitgeliefert.

> Diese Software ersetzt keinen Fluglehrer. Alle Flugzeug- und Platzwerte sind ungeprüft.
